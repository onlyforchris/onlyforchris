## 做过的东西

### [HTML 幻灯片](https://github.com/onlyforchris/html-ppt-apple-style)

把演示做成一个 HTML 文件，浏览器打开就能放映。可以直接改模板，也可以作为 Skill 使用。

[打开博客演示](https://onlyforchris.github.io/blog/apple-demo.html) · [取用模板](https://github.com/onlyforchris/html-ppt-apple-style/blob/master/assets/apple-ppt-template.html)

### [财小盒](https://github.com/onlyforchris/caixiaohe)

Windows 桌面财务工具：发票查重、归档，加上现金流预测。账本保存在本机；可选云端 OCR 会涉及票据上传，使用前请确认配置。

### [JD 简历匹配](https://github.com/onlyforchris/match-resumes-to-jd)

先从 JD 建岗位画像，再逐份整理简历证据和待核验问题。没写不等于不符合，也不编一个看似精确的分数。需要支持 Skill 的 AI 工具。

### [公众号草稿发布](https://github.com/onlyforchris/wechat-draft-publisher-skill)

Markdown 转微信排版、上传图片、创建草稿。到草稿箱为止，不直接群发；需要公众号 API 凭据。

<sub>基于 [wechat-publisher](https://github.com/jiji262/wechat-publisher) 裁剪的衍生版本。</sub>

### [中文标书辅助](https://github.com/onlyforchris/bid-response-production)

把招标要求、响应内容和证据材料对应起来，辅助审查与 Word 排版。缺材料的地方留给人核实，不替代业务或法务审核。

### [Agent Hub](https://github.com/onlyforchris/agent-hub)

Python + SQLite 的本地工作区，提供查询状态、列出和创建工作区的 MCP 工具。目前是基础版，不是生产级多租户平台。
